# Validation record · 18 September 2026

## Automated checks

- Node.js 24; Next.js 16.3.5 production compilation and route generation.
- ESLint and TypeScript checks.
- Ten unit regressions: binary outcome parsing, invalid/closed data, quantity rounding, order fields/freshness, score bounds, trusted geo headers, rate budgets, history window coverage and execution sequencing.
- Eight Playwright tests, including Signals → inspector → desk → ticket, search/filter/window changes, Markets navigation, command search, chart controls, feed failure recovery, Guide, Portfolio entry and 404.
- WCAG A/AA automated axe scans on public product surfaces at 375, 768, 1024 and 1440px; zero violations in the tested states.
- Document overflow assertions at all four widths; reduced-motion setting and keyboard activation/escape covered.
- Dependency audit: 0 critical, 0 high, 27 moderate after compatible updates. Remaining findings are documented in the audit and roadmap.

Browser API responses are deterministic test fixtures; screenshots generated by these tests illustrate layout and behavior, not current market conditions. Production/local live reads were also inspected separately.

## Visual review

- Stronger workspace headings, legible secondary copy and a consistent Geist numeric hierarchy.
- Room for event titles, probability, implied/actual values and the primary inspector action.
- Focus visibility and button contrast on selected filters, order sides and form controls.
- Responsive signal sheet and mobile desk tabs; no document-wide horizontal overflow. Wide market tables can scroll within their own container.
- Guide typography wraps cleanly on a narrow screen; sticky app navigation remains reachable.
- Ticket errors appear above its primary action; zero/invalid order estimates do not become executable orders.

Evidence screenshots are in [screenshots](screenshots/). Regenerate the complete viewport set with `npm run test:e2e`; outputs are written to ignored `test-results/`.

## Verification limits

No funded-account action or wallet signature was performed. Login provider settings, authenticated Portfolio content, venue acceptance, builder attribution, deposits/withdrawals, partial fills and live account reconciliation require an owner-controlled integration check. Preview has public Privy identity but lacks production signing secrets; its auth behavior is distinct from the unconfigured local environment.

Figma is a direction exploration board; the implementation and browser evidence are the source of truth for final layout. Automated accessibility checks cover the tested states and do not certify complete WCAG conformance.
